Objective: 
Implement and analyse the ChannelNet framework for OFDM channel estimation. Represent the channel 
time–frequency response as a two-dimensional image and reconstruct the complete channel response from 
noisy, sparse pilot observations using a two-stage deep-learning pipeline: image super-resolution (SR) 
followed by image restoration (IR)/denoising. 
Reference Paper: 
Mehran Soltani, Vahid Pourahmadi, Ali Mirzaei, and Hamid Sheikhzadeh, “Deep Learning-Based Channel 
Estimation,” arXiv:1810.05893v4, 19 February 2019. 
 
System and Simulation Setup: 
Parameter 
Required specification 
System configuration 
SISO-OFDM (one transmit antenna and one receive antenna). 
Time–frequency grid 
72 subcarriers × 14 OFDM time slots, following the LTE-like setup in the 
paper. 
Pilot arrangement 
Lattice-type pilot arrangement. Use 48 pilots per frame for the main 
comparison and evaluate at least two additional pilot densities. 
Channel models 
Vehicular-A (VehA) and SUI5. Use the Vienna LTE simulator available in the 
zip file.  
Channel representation 
Represent the complex channel using two normalized 2-D images: real and 
imaginary parts. 
Learning input and target 
Input: sparse/noisy LS channel estimates at pilot locations.  
Target: complete ground-truth channel grid. 
Evaluation metric 
Mean-square error (MSE) between the estimated and ground-truth channel 
responses.
